Deservefirst Modules Package
============================

This archive contains three modules:
- CoreModule
- CMSModule
- RBACModule

To use:
1. Copy the module folders into your monorepo or packages/ directory.
2. Run `npm install` in each package to install dependencies.
3. Wire up CoreModule.initializeCoreModule() with your MYSQL_URL and REDIS_URL and boot the app.

Each module has a DOCUMENTATION.md with more details.
