# @deservefirst/Proposals

This module is for Proposals generation

## Installation

```bash
npm install @deservefirst/Proposals
```

## Usage

```typescript
import { ProposalsModule } from '@deservefirst/Proposals';

// Add to your NestJS app
@Module({
  imports: [ProposalsModule],
})
export class AppModule {}
```
