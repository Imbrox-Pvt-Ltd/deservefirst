## Welcome to Deservefirst
Deservefirst is a powerful e-commerce platform that lets you create, manage, and grow your online store with ease. This guide is designed for merchants, store admins, and system admins to get started and make the most of the platform.

### Getting Started
1. **Sign Up**:
   - Visit `https://deservefirst.com/signup`.
   - Create a tenant account and set up your store.
2. **Access Your Store**:
   - Merchant Dashboard: `http://merchant.deservefirst.com`
   - Storefront: `http://store.deservefirst.com`
   - Admin Panel (system admins): `http://admin.deservefirst.com`
3. **Configure Your Store**:
   - Navigate to Merchant Dashboard > Store Settings.
   - Set store name, currency, and timezone.

### Managing Products
- **Add a Product**:
  - Go to Merchant Dashboard > Products > Add Product.
  - Enter details (name, price, description, SEO metadata).
- **Categories**:
  - Organize products in Merchant Dashboard > Categories.
- **SEO**:
  - Edit meta titles/descriptions in Merchant Dashboard > SEO.

### Managing Orders
- **View Orders**:
  - Go to Merchant Dashboard > Orders.
- **Process Refunds**:
  - Select an order, click “Refund” (uses original FX snapshot).

### Customizing Your Storefront
- **Themes**:
  - Go to Merchant Dashboard > Themes.
  - Choose or customize a theme using the Storefront Builder.
- **Path Hinting** (Admins):
  - Enable in Admin Panel > Themes > Settings.
  - Visit `http://store.deservefirst.com?hinting=1` to debug templates.

### Translations
- **Manage Languages**:
  - Go to Merchant Dashboard > Translations.
  - Add/edit translations for your store.
- **Health Check**:
  - View missing translations in Translation Health dashboard.

### Logs and Analytics
- **Store Logs**:
  - View tenant-specific logs in Merchant Dashboard > Logs.
  - Share logs with support via signed URLs.
- **Analytics**:
  - Monitor sales and traffic in Merchant Dashboard > Analytics.

### Support
- **Create a Ticket**:
  - Go to Merchant Dashboard > Support > New Ticket.
- **Contact**:
  - Email: info@deservefirst.com
  - Website: https://deservefirst.com/support

### Security
- **Permissions**:
  - Manage user roles in Merchant Dashboard > Permissions.
- **Data Safety**:
  - All data is encrypted and tenant-isolated.

### FAQs
- **How do I change my store’s currency?**
  - Go to Merchant Dashboard > Settings > Currency.
- **How do I shard my store?**
  - Contact support for tenant sharding (system admins only).

For developer documentation, see `https://developers.deservefirst.com`.
